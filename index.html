vue-basics.live

Empat directive yang mengikat, menyembunyikan, menampilkan, dan mengulang.

Geser slider, klik tombol, ubah teks — setiap demo di bawah ini adalah aplikasi Vue 3 yang benar-benar hidup, bukan sekadar ilustrasi. Kodenya persis seperti yang tampil di panel sebelah kanan.

01

v-bind DATA → ATRIBUT

v-bind (disingkat :) menghubungkan sebuah atribut HTML — seperti style, class, atau src — ke sebuah nilai di data Vue. Saat nilainya berubah, atribut ikut berubah otomatis, tanpa perlu menyentuh DOM secara manual.

LIVE PREVIEW
{{ size }}px
KODE
<!-- warna & lebar terikat ke data -->
<div
  :style="{
    backgroundColor: color,
    width: size + 'px'
  }">
  {{ size }}px
</div>

<input type="color" v-model="color">
<input type="range" v-model="size">
Inti: v-bind mengubah atribut, bukan menyembunyikan atau mengulang elemen. Ini fondasi untuk semua binding dinamis di Vue — termasuk :class dan :src.
02

v-if TAMBAH / HAPUS DOM

v-if benar-benar menambahkan atau menghapus elemen dari DOM tergantung kondisinya. Saat kondisi false, elemen itu tidak ada sama sekali di halaman — bukan disembunyikan, tapi dihapus.

LIVE PREVIEW
Elemen ADA

— elemen dihapus dari DOM —

Elemen kotak ada di DOM: {{ tampil ? 'YA' : 'TIDAK (dihapus)' }}
KODE
div v-if="tampil">
  Elemen ADA
</div>
<p v-else>
  Elemen TIDAK ADA di DOM
</p>

<button @click="tampil = !tampil">
  Toggle
</button>
Inti: Cocok untuk kondisi yang jarang berubah (misalnya role user, hasil login) karena ada biaya render/hapus ulang tiap kali kondisi berganti.
03

v-show CSS DISPLAY

v-show selalu me-render elemennya ke DOM — yang berubah hanya CSS display: none. Elemen tetap "ada", cuma disembunyikan secara visual. Bandingkan langsung dengan v-if di atas.

LIVE PREVIEW
Elemen ADA (tersembunyi via CSS)
Elemen kotak ada di DOM: YA (selalu) · Terlihat: {{ tampil ? 'YA' : 'TIDAK' }}
KODE
<div v-show="tampil">
  Elemen ADA (tersembunyi via CSS)
</div>

<!-- selalu di-render;
     hanya style="display:none"
     yang berubah -->
Inti: Lebih efisien untuk toggle yang sering berubah (tab, dropdown, accordion) karena elemen tidak dibuat-ulang, hanya disembunyikan.
04

v-for RENDER LIST

v-for mengulang sebuah elemen untuk tiap item dalam array. Setiap item butuh atribut :key yang unik, supaya Vue tahu persis elemen mana yang berubah saat list-nya di-update.

LIVE PREVIEW
  • {{ item.text }} ✕
Jumlah item: {{ items.length }}
KODE
<ul>
  <li
    v-for="item in items"
    :key="item.id">
    {{ item.text }}
  </li>
</ul>

// data
const items = [
  { id: 1, text: 'Belajar Vue' },
  { id: 2, text: 'Coba v-for' }
]
Inti: Tanpa :key yang stabil, Vue bisa salah "mengenali" elemen mana yang berpindah saat list berubah — sering jadi sumber bug UI yang membingungkan.
Bonus: apa bedanya :key="item.id" vs :key="index" (atau tanpa key)?

Vue butuh :key untuk mencocokkan elemen DOM lama dengan data baru saat list berubah urutannya. Kalau key-nya stabil (mis. item.id), Vue tahu persis "elemen mana pindah ke mana". Kalau key-nya tidak stabil — pakai index, atau tanpa :key sama sekali — Vue hanya mencocokkan berdasarkan posisi, bukan identitas item. Efeknya baru kelihatan saat ada elemen dengan state di luar data reaktif, misalnya teks yang sedang diketik di input. Coba sendiri di bawah ini:

  1. Ketik teks yang berbeda-beda di tiap kotak input (misal "satu", "dua", "tiga").
  2. Klik "Tambah item baru di atas", lalu perhatikan ke mana teks ketikanmu ikut pindah.
LIVE PREVIEW — coba ganti mode key-nya
  • {{ item.label }}
Karena key mengikuti identitas item (id), teks ketikanmu tetap menempel pada item yang sama meski posisinya bergeser ke bawah. Karena key mengikuti posisi (index), Vue menyamakan input lama dengan urutan baru apa adanya — teks ketikanmu tertinggal di posisi lama, jadi terlihat "tertukar" ke item yang salah.
